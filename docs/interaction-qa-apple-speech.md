# Apple / 系统声音整合验收 · 2026-11-04

基线：主线 `73bf3c2`，开发构建沿用 1.1.2 元数据，未提升公开发行版本。Mac 原生组件独立安装、本地临时签名，尚未签名公证发行。

## 已验证

- `npm run check`：中英词典检查、lint（0 Error，存量及测试脚本 Warning 单列）、146 个 JavaScript 测试、4 个 Python 测试、更新说明测试和生产构建通过。
- `scripts/build-apple-helper.sh`：Swift 6.4 / macOS 27.0.1 / Apple silicon 编译与代码签名完整性通过。
- 真实 Apple 模型识别：`今天我们测试乔木语音。会议定在星期五下午三点，请大家提前准备好材料。`，结果保留主要内容，系统将“三”规范成“3”。中文模型已存在；英文模型缺失状态正确返回。
- 独立 Obsidian 1.15.0 测试库：真实系统声音采集约 9.48 秒，使用真实 Apple 模型转写；命令启动和结束后，文字写入指定光标位置，WAV 附件保存且可读，取消后无迟到插入。系统默认麦克风不变，不安装虚拟驱动。
- 实际设置页确认 Apple 选项、模型准备、语言选择和保留录音开关。设置窗口是 Obsidian 独立窗口；测试脚本只调用一次 `setEnable(true)`，不再额外 `enablePlugin` 导致双实例。
- 协议回归：Ming 使用官方 `audio_url`，禁用思考，拒绝截断/缺失回复；密钥按服务独立保存。原有 MiMo / Doubao / OpenAI 协议测试继续通过。
- 生命周期：本次子进程取消、卸载、启动中取消、非法流式帧和临时音频清理均有回归；实机取消无残留转写。

## 未验证 / 限制

- 没有真实 Ling / Ming Key：尚未验证 Ming 账号权限、计费、免费额度或真实云端识别质量。
- 未做真实人声麦克风、多小时长录音、拔插音频设备、旧系统/Intel Mac、Windows/Linux/手机硬件验收。跨平台原有功能由现有自动检查覆盖，不代表真机通过。
- Apple「自动」暂映射中文；多语言需要明确选择并准备对应模型，不宣称自动检测或混合语言准确性。
- 录音保存在本次操作内存中；这次整合没有引入 Cicada 的崩溃恢复录音格式。
- 未发布新插件版本或公证安装包。此文记录源码及本机开发构建证据，不能作为社区商店新版本可用证明。
