Read any note aloud and dictate straight into notes. Read the selected text, start at your cursor, or follow the visible reading view. Pause, resume, change speed and voices, and keep reading highlights in sync.

Cloud TTS and speech-to-text settings include clickable API-key application links and setup guides. Required fields stay visible, keys can be shown or hidden, and successful tests are cleared after settings change. ASR keys are isolated by provider; cancelled or outdated connection tests cannot report success.

Cloud recognition supports SiliconFlow, Doubao, GLM, StepFun, Xiaomi MiMo, Groq and OpenAI. Local SenseVoice, Kokoro and MeloTTS use an optional external runtime; the plugin downloads model data only. System speech, Mac speech and Edge TTS need no API key. Failed dictation retains the recording for retry or saving.

English and Simplified Chinese interfaces. Desktop-only local features are kept separate from mobile cloud/system speech. macOS Obsidian host checks and automated tests are recorded in the repository; Windows and Linux CI do not establish device playback, and mobile device testing is not yet complete.
