导出分享：把选中文字、指定章节或整篇笔记导出为 MP3 音频、MP4 视频，并可附带 SRT 字幕和封面图。横版、竖版视频支持频谱、圆环、实时波形和响度条，字幕随语音推进，可保留正文强调、添加封面与个人片尾。

分享窗口复用现有语音和最近使用组合，支持试听、调整文字、不变调加速与取消。文件默认保存到笔记附件位置；桌面可选择库外目录，同名文件自动另存。生成成功后可按需插入笔记。

本版本包含视频字幕所需的逐词计时引擎，尚未接入阅读界面的逐词高亮，不将其列为读时新功能。新增 MP3/MP4 编码依赖的许可证已随源码保留；开发依赖 Moment 已锁定修复版。

验证：131 个 JavaScript 与 4 个 Python 测试通过；交接记录提供了 macOS 系统音色的真实 MP3、SRT、PNG、横竖 H.264/AAC 视频验收。豆包 ASR 真实接口用合成英文 WAV 识别通过，未验证麦克风录音全链路。Windows 的真实 Obsidian 导出补测正在运行，最终结果将在公开前写入。

未验证：Linux、手机硬件、付费 TTS 的导出、Edge 在线音色导出（按用户要求取消补测）、真人听辨加速音频和空文件夹选择器。ASR 识别通过不等于 TTS 合成或导出通过。移动端仅开放音频；设备不支持视频编码时提示改用 MP3。
